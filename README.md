# 📖 Overview

Mellow – Play & Relax is a modern music streaming application built using **React** and **Vite**. The application provides a premium music listening experience with an elegant UI, responsive design, intelligent playlist management, search functionality, queue management, user authentication, and many more advanced features.

The frontend communicates with the backend through REST APIs and provides a seamless experience across desktop and mobile devices.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Matrixuse/Mellow-Frontend-main.git
```

Navigate to project

```bash
cd Mellow-Frontend-main
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

---

# 🌐 Environment Variables

Create a `.env` file.

```
VITE_API_BASE_URL="get the backend render URL in readme of backend repository"
```
